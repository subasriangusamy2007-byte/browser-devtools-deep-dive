# browser-devtools-deep-dive
Browser DevTools Deep Dive

About

This project explores browser Developer Tools and their uses in debugging websites.

1. Elements Panel

Tip: The Elements panel helps inspect HTML elements and CSS styles.

2. Console Panel

Tip: The Console panel helps identify JavaScript errors and display messages.

3. Network Panel

Tip: The Network panel helps monitor website requests and response status.

4. Sources Panel

Tip: The Sources panel helps view source files and debug JavaScript using breakpoints.

Note: Sources panel was not available in the TrainingTrains mobile DevTools interface.

5. Application Panel

Tip: The Application panel helps inspect Local Storage, Session Storage and Cookies.

Conclusion

Browser Developer Tools help developers inspect, test and debug websites efficiently.
